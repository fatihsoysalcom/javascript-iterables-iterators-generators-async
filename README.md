# JavaScript Iterables Iterators Generators Async

This example demonstrates JavaScript's Iterables and Iterators. It covers built-in iterables, creating custom iterable objects using the `[Symbol.iterator]` method, and simplifying iteration with generator functions. Finally, it showcases asynchronous iteration using `for await...of` with an async generator.

## Language

`javascript`

## How to Run

1. Ensure Node.js is installed.
2. Save the code as `main.js`.
3. Run from your terminal: `node main.js`
